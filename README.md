# Guideline-Grounded Clinical Q&A Agent

A retrieval-augmented (RAG) agent that answers questions over public
CDC/WHO clinical guideline documents, returning citation-grounded
passages and declining to answer when retrieval confidence is low.

**Informational only — no diagnostic or treatment advice. Not a
deployable clinical tool.**

## Status

Early scaffolding. See [PLAN.md](PLAN.md) for the day-by-day build plan.

## Stack

Python, LangChain, FAISS (vector store), AWS Bedrock (LLM), Streamlit,
Docker.
